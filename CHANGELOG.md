# Changelog

## 1.0.0
- Initial public release.
- Unlocks DLSS Multi Frame Generation 5X and 6X directly in the Farming Simulator 25 graphics menu.
- Includes patch layouts for FS25 1.19.0.0, 1.20.0.0 and 1.21.0.0.
- Adds experimental compatibility scanning for future game builds.
- Enables FS25 development controls for FPS above the normal in-game limiter.
- Automatically detects `game.xml` and the game build from the `VERSION` file.
- Creates backups and provides Restore Original.
- Detects NVIDIA GPU generation and offers guided Ada MFG helper installation for RTX 40 Series users.
- Distributed as a single standalone Windows x64 executable.
- Full source code and reproducible GitHub Actions build workflow included.
